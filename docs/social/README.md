# Daily Support Guide Social System

This folder contains the advisory social AI agent system for Daily Support Guide.

Current status: planning and draft review only.

Active files:

- `social-agent-team-protocol.md`: team roles, boundaries, workflow, and approval gates.
- `social-post-review-checklist.md`: safety and quality checklist for every social draft.
- `weekly-social-calendar-template.md`: weekly calendar structure for Threads, Instagram, and Facebook drafts.

Phase 1A restrictions remain active:

- No automatic social posting.
- No platform API connection.
- No ads.
- No tracking links.
- No affiliate links.
- No product, brand, retailer, supplement, dosage, diagnosis, or treatment advice.

Founder approval is required before any social draft becomes a live post.
