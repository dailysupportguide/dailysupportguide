## Article Draft

# Product Comparison Notes: A Simple Sheet for Keeping Facts Straight

Product comparison notes work best when they are boring in a useful way. The same fields, used every time, keep a bright claim or one dramatic review from taking over the whole decision.

This article explains a simple note sheet for comparing product information. It does not name brands, recommend products, choose winners, or replace medical, financial, or professional advice.

## Start with one comparison question

Before listing details, write one question both products must answer. The question might be about package amount, label facts, total cost, return terms, or what information is missing.

FTC online shopping guidance tells consumers to check sellers and products, learn total cost, read product descriptions including fine print, and read delivery, return, and refund policies. Those steps fit well into a note sheet.

## Use fixed fields

Use the same fields for each item: description, package or amount, key label facts, total cost, unit price if shown, reviews, delivery terms, return terms, and open questions.

Fixed fields make comparison easier because every item has to answer the same set of questions. If a field is missing, write "not shown" instead of filling it in.

## Keep cost separate

NIST explains that unit pricing is pricing based on cost per unit of measure. Unit price may help compare value when package sizes differ, but it should stay in its own field.

A low price, low unit price, or large package should not automatically become a recommendation. Keep total cost, package size, serving count, shipping fees, and unit price separate enough to see what each number measures.

## Read reviews as supporting notes

FTC consumer guidance says to read reviews with a critical eye, check several sources, and avoid relying only on star ratings because some reviews and ratings can be fake or misleading.

In a note sheet, reviews belong in a supporting field. Repeated comments about size, clarity, delivery, support, packaging, or mismatch with the description can be useful. One dramatic comment should not replace the label or terms.

## Record terms before deciding

FTC online shopping guidance points readers to delivery, return, and refund policies. These details can change the practical comparison, especially when two items look similar.

Write terms in plain fields: expected delivery, refund window, return shipping, restocking fee if shown, support route, and any limits. Do not assume two sellers or products use the same terms.

## Leave open questions visible

A good note sheet does not force every comparison into a winner. If important information is missing, write the question that remains.

If the comparison involves a medical condition, medication, pregnancy, allergy, surgery, eating disorder history, or personal nutrition plan, keep the question unresolved and follow licensed professional guidance.

## A practical takeaway

Product comparison notes are useful when they keep description, package amount, label facts, total cost, reviews, terms, and open questions in separate fields. This article is general education only and is not medical advice.
